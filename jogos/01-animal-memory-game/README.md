# Animal Memory Game

## Sobre o jogo

O Animal Memory Game é um jogo da memória com cartas numeradas. Em cada rodada, o aluno escolhe duas cartas e tenta relacionar o nome de um animal em inglês à sua imagem correspondente.

O jogo possui três rodadas, com cinco animais em cada uma. As cartas ficam embaralhadas e apresentam números no verso, permitindo que o aluno escolha dizendo, por exemplo, “I want number 1 and number 2”.

## Objetivo da aula

Reforçar o reconhecimento e a associação entre o vocabulário escrito dos animais em inglês e suas representações visuais, incentivando também a participação oral dos alunos durante a escolha das cartas.

## Conteúdo trabalhado

- Vocabulário de animais em inglês.
- Reconhecimento visual e leitura de palavras.
- Associação entre palavra e imagem.
- Expressões simples para escolher cartas, como “I want number...”.

## Como funciona

1. O professor abre o jogo no navegador.
2. O aluno escolhe duas cartas usando os números que aparecem no verso.
3. As cartas revelam uma palavra ou a imagem de um animal.
4. O objetivo é encontrar o par correspondente.
5. Ao completar os cinco pares, o aluno avança para a próxima rodada.

O jogo tem três rodadas e pode ser reiniciado pelo botão **SHUFFLE**.

## Tecnologias utilizadas

O jogo foi desenvolvido em um único arquivo HTML, utilizando:

- **HTML5:** estrutura e elementos da página.
- **CSS3:** cores, layout, responsividade e animação de virar as cartas.
- **JavaScript puro (Vanilla JavaScript):** embaralhamento, controle das rodadas, seleção das cartas, verificação dos pares e atualização da tela.

Não foram utilizadas bibliotecas, frameworks ou dependências externas.

## Arquivos

- `index.html`: código completo do jogo, com HTML, CSS e JavaScript no mesmo arquivo.

## Como executar

Baixe ou abra o arquivo `index.html` em um navegador atualizado. Não é necessário instalar nada.
