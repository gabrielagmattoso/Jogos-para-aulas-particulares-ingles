# Jogos para Aulas Particulares de Inglês

Este repositório reúne jogos educativos e interativos desenvolvidos para apoiar as aulas particulares de inglês. A proposta é transformar conteúdos trabalhados em aula em atividades lúdicas, visuais e participativas, respeitando o nível de aprendizagem dos alunos.

Os jogos são pensados como materiais de apoio para o professor: cada atividade apresenta seu próprio objetivo pedagógico, os conteúdos trabalhados e uma orientação de aplicação.

## Jogos disponíveis

| Jogo | Objetivo principal | Tecnologias |
|---|---|---|
| [Animal Memory Game](jogos/01-animal-memory-game/) | Relacionar nomes de animais em inglês às suas imagens | HTML, CSS e JavaScript |
| [School Race](jogos/02-school-race/) | Praticar frases em Present Continuous com vocabulário escolar, em uma corrida entre dois alunos | HTML, CSS e JavaScript |
| [Monster Battle](jogos/03-monster-battle/) | Ler e imitar frases em Present Continuous com vocabulário escolar, em uma batalha de monstros entre dois alunos | HTML, CSS e JavaScript |

## Organização do repositório

Cada jogo fica em sua própria pasta dentro de `jogos/`. Nela, você encontrará:

- `README.md`: apresentação do jogo, objetivo da aula, conteúdo trabalhado e dinâmica sugerida.
- Arquivo(s) do jogo: código necessário para executar a atividade.

## Tecnologias

Os jogos podem utilizar tecnologias diferentes, conforme a necessidade de cada atividade. Sempre que possível, serão priorizadas soluções simples, acessíveis e fáceis de executar no navegador.

No desenvolvimento dos códigos, a preferência é por HTML, CSS e JavaScript puros (Vanilla JavaScript), sem frameworks ou bibliotecas desnecessárias.

## Padrão de desenvolvimento

Para manter os projetos consistentes e fáceis de compreender e atualizar:

- usar uma estrutura simples e organizada;
- escolher nomes claros para variáveis e funções;
- dividir o comportamento em funções pequenas e objetivas;
- comentar trechos quando isso ajudar a explicar a lógica;
- evitar recursos avançados ou dependências sem necessidade;
- preservar, nos próximos jogos, o estilo de código já utilizado nos projetos anteriores.

## Como utilizar

1. Acesse a pasta do jogo desejado.
2. Leia o README específico para entender a proposta pedagógica e a dinâmica.
3. Abra o arquivo HTML no navegador, quando o jogo for desenvolvido para execução local.
